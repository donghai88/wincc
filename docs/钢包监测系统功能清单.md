## 待讨论明细

### 1. 登录鉴权深化
- 是否对接统一认证 / 真实账号接口
- 角色权限（只读 / 操作员 / 管理员）是否要区分
- 登录态过期、退出增强、改密等是否本期要做

### 2. 今日识别准确率
- 是否本期要上（当前页面为 `—`）
- 统计口径：识别成功次数 / 总次数？是否含人工复核？
- 接口字段、统计周期（自然日）、刷新频率

### 3. 实时监控（工位/设备绑定）
- 四路工位与设备 ID 是否由后端固定下发槽位映射（避免只靠数组顺序）
- 设备改名/增减后，播流、温度、截图三路是否必须严格同槽对齐
- 离线判定规则是否还需调整（当前：三温任一为空或负值即离线）
